# Suporte do Sparta Desktop 0.9.0

Fonte de verdade: `docs/support.md`.

- canal: GitHub Issues;
- formulário: `.github/ISSUE_TEMPLATE/bug-report.yml`;
- sem e-mail pessoal, telemetria ou crash reporting;
- Desktop 0.9.0 não grava log persistente;
- `%APPDATA%\Sparta` é dado sensível do Electron e não deve ser anexado;
- relatos devem omitir tokens, senhas, `.env`, dumps, Local Storage e dados de outro jogador.
