1. Elegibilidade

Para usar o Sparta você precisa ter uma conta Riot Games válida e atender aos requisitos de idade e demais condições estabelecidos pela própria Riot Games para manter essa conta. O Sparta não define regras de idade próprias, adicionais às da Riot.

2. Conta Sparta

Você é responsável por manter a confidencialidade da sua senha e por qualquer atividade realizada com sua conta. Contas podem ser suspensas em caso de uso indevido, tentativa de acesso a dados de outra conta, ou abuso da API do Sparta.

3. Uso permitido

O Sparta é destinado a uso pessoal, para análise do seu próprio histórico de partidas. Não é permitido: tentar acessar dados de contas que não são suas; fazer engenharia reversa com o objetivo de contornar limites de autorização; usar o serviço para automatizar ações dentro do cliente do League of Legends (o Sparta em si nunca faz isso, e usá-lo como base para isso viola estes termos).

4. Integração com a Riot Games

O Sparta lê dados através da Riot Games API e, quando o cliente do League está aberto, observa (sem nunca modificar) a sessão local do League Client.
